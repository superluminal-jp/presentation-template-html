# Contract: `data-pptx` 役割属性(HTML 作者向け)

**Feature**: 011-pptx-dom-extraction | **Data model**: [../data-model.md](../data-model.md)

正本デックのコンポーネントが、編集可能な PowerPoint オブジェクトへ変換されるための契約。
変換器はこの語彙**だけ**を知る。コンポーネント名やクラス名は一切参照しない。

## 原則

1. **既定は「出力しない」**。`data-pptx` で明示的にマークされた要素だけが PPTX へ出る。
2. **役割属性は描画に影響しない**。CSS セレクタの対象にしてはならない。
3. **コンポーネントは語彙の合成で表現する**。語彙に写せない視覚表現(グラデーション、影、
   擬似要素による本文文字)を新規コンポーネントに持ち込まない。

## 語彙

| 値 | PPTX 上の対応物 | 付ける対象 |
|---|---|---|
| `text` | テキストボックス | 実 DOM テキストを持つ末端要素 |
| `shape` | 矩形(角丸可) | 塗り・境界を持つ面 |
| `line` | 直線 | 罫線、コネクタ |
| `table` | ネイティブ表 | `<table>` 要素 |
| `chart` | ネイティブグラフ | `data-chart` を持つ多系列 SVG |
| `image` | 画像 | `<img>`(本文領域では原則不使用) |
| `group` | グループ | 複合コンポーネントの根 |
| `ignore` | 出力しない | 装飾、注釈パネル、グリッドガイド |

## 作成規則

### `text`

- 本文は実 DOM のテキストノードであること。擬似要素で文字を描かない。
- 1 要素 = 1 テキストボックス。要素内の部分着色(`<span class="u-accent">` 等)は
  混在ランとして保持されるため、着色のためにボックスを分割しない。
- フォント・サイズ・色・行揃えは計算済みスタイルから取られる。変換のために追加の属性を付けない。

### `shape` / `line`

- 塗り・境界色・境界太さ・角丸半径は計算済みスタイルから取られる。
- グラデーション・影は PPTX に対応物が無い。単色塗りと 1 本の境界で表現する。
- `line` は幅または高さが 0 に近い要素、もしくは明示的な罫線要素に付ける。

### `table`

- `<table>` / `<thead>` / `<tbody>` / `<th>` / `<td>` の意味的マークアップであること。
- ヘッダ行は `<th>` で表現する(ネイティブ表のヘッダ書式へ写される)。
- 表を `<div>` の格子で模さない。模した場合はネイティブ表にならない。

### `chart`

- `data-chart` に下記 JSON を持つこと。

```json
{
  "type": "bar | line | bar100 | doughnut | scatter",
  "categories": ["Q1", "Q2", "Q3", "Q4"],
  "series": [
    { "name": "企画", "values": [10, 12, 14, 15] },
    { "name": "開発", "values": [22, 25, 27, 30] }
  ]
}
```

- **整合制約**(`check:pptx` が検証。違反はビルド失敗):
  - `series.length` == 同要素の `data-series` の値
  - `series[].name` の集合 == 同 SVG 内の `text.series-label` の文言の集合
  - `series[].values.length` == `categories.length`(`scatter` を除く)
- 系列色は `--cat-1..7` を系列順に割り当てる。個別指定しない。

### `group`

- 複合コンポーネント(`.callout`、`.stat`、`.step-nav__item`、`.tile`、`.node` など)の根に付ける。
- グループ自身は描画されない。子孫の `shape` / `text` がまとまって 1 グループになる。
- 入れ子可。PowerPoint 上でコンポーネント全体を一塊で移動できるようにするためのもの。

### `ignore`

- 子孫ごと出力対象から外れる。
- 対象: `.slide__annotation`(設計意図パネル)、`.grid-guide`、純粋な装飾要素、
  `aria-hidden` の装飾文字。

## 新規コンポーネントのチェックリスト

新しいコンポーネントを正本へ追加するとき、以下を満たすこと。

- [ ] 根に `data-pptx="group"` がある(複合の場合)
- [ ] 本文文字がすべて実 DOM のテキストノードである(擬似要素で描いていない)
- [ ] 面は単色塗り + 1 本の境界で表現している(グラデーション・影を使っていない)
- [ ] 表形式のデータは `<table>` で表現している(`<div>` の格子で模していない)
- [ ] グラフは `data-chart` payload を持ち、整合制約を満たす
- [ ] 装飾要素に `data-pptx="ignore"` を付けた
- [ ] 役割属性を CSS セレクタの対象にしていない
- [ ] `npm run test:visual` の差分が 0(役割属性の追加が描画を変えていない)
